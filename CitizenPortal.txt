Complete flow :
===============

		User Browser
			↓
		React Frontend
			↓
		Azure Front Door / DNS
			↓
		Azure Application Gateway or NGINX Ingress
			↓
		Spring Cloud Gateway
			↓
		┌───────────────────────────────┐
		│ Auth Service                  │
		│ Citizen Service               │
		│ Master Service                │
		│ Document Service              │
		│ Search Service                │
		│ Notification Service          │
		└───────────────────────────────┘
			↓
		PostgreSQL / OpenSearch / Redis / Kafka
		
| Layer                     | Responsibility                        |
| ------------------------- | ------------------------------------- |
| Azure App Gateway / NGINX | External traffic, SSL, Ingress        |
| Spring Cloud Gateway      | API routing, JWT, filters, rate limit |
| Microservices             | Business logic                        |
| PostgreSQL                | Main data                             |
| OpenSearch                | Fast search                           |
| Redis                     | Cache                                 |
| Kafka                     | Event sync                            |
